# Theme Center

Главная палитра живёт в [palette.sh](palette.sh).

Как менять цвета:

1. Правишь значения в `~/.config/theme/palette.sh`.
2. Запускаешь `~/.config/theme/apply.sh`.
3. Перезапускаешь приложение, чтобы оно перечитало цвета.

Что обновляется из одного центра:

- `theme/generated/ui-colors.css`
- `kitty/colors.conf`
- `yazi/theme.toml`
- `btop/themes/miku_light.theme`
